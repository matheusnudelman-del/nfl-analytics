# NFL Analytics Dashboard

A web dashboard comparing all 32 NFL teams using advanced stats.

**Live site:** [add your Vercel link here]

## Features
- Offensive and defensive EPA per play for every team
- Win-loss record and points per game
- Sort by any stat, search by team name, and filter by conference

## Built with
- Next.js
- TypeScript
- Tailwind CSS
